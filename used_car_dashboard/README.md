# Used Car Listings Dashboard

A Plotly Dash dashboard for exploring used car listing prices, mileage, vehicle years, fuel types, seller types, and make/model trends.

## How to run locally

```bash
pip install -r requirements.txt
python app.py
```

Then open the local Dash URL shown in your terminal, usually:

```text
http://127.0.0.1:8050
```

## Files

- `app.py` - Dash dashboard code
- `used_car_listings.csv` - dataset
- `requirements.txt` - Python dependencies
